# Gradient descent reaches arbitrary accuracy in a fixed number of large steps on multiclass logistic regression

Andreea-Alexandra Musat and Nicolas Boumal<sup>∗</sup>

October 20, 2026

## Abstract

We show that gradient descent (GD) with step size η can achieve ε optimality gap on the multiclass logistic regression loss in a number of iterations T that is independent of ε. To do so, the step size η must be chosen large enough as a function of ε (and properties of the linearly separable dataset), while T is a constant that only depends on the data. The relevant properties of the data include the number of points and their margin (for T), and one additional quantity (for η) that turns out to be necessary in dimension $d \geq 3 .$ The proofs build on the known fact that, as $\eta  \infty ,$ suitably rescaled GD becomes the perceptron algorithm, and the latter finds a perfect classifier in T iterations. A similar claim was shown for two classes in dimension $d = 2$ using other proof techniques.

This result adds to previous works that showed GD on the logistic regression loss can be accelerated by taking large step sizes. Those provoke a wild, oscillatory initial phase, followed by a stable phase. We provide results of this (qualitatively diferent) nature, too.

## 1 Introduction

Traditional convex optimization theory prescribes a “small” step size for gradient descent. For an L-smooth convex objective, a step size $\eta < 2 / L$ ensures that the loss decreases at every iteration and yields the standard $\mathcal { O } ( 1 / T )$ convergence rate in function value.

For logistic regression on linearly separable data, Wu et al. (2024) studied gradient descent (GD) with constant step sizes well above this classical threshold. Although the loss may initially oscillate and the usual descent lemma no longer applies, they showed that GD still converges and, perhaps surprisingly, the loss decays at an $\widetilde { \mathcal { O } } ( 1 / T ^ { 2 } )$ rate, improving on the standard bound. In this setting, the nonmonotonic behavior usually associated with instability can instead improve optimization eficiency.

The analysis of Wu et al. (2024) identifies two phases in the dynamics. The iterates first pass through an unstable region, in which the loss may oscillate, before entering a stable region after $\tau =$ $\mathcal { O } ( \eta )$ iterations. Once in the stable region, the loss decreases at every iteration. Then, for an iteration budget T, they show that choosing $\eta = \Theta ( T )$ yields an accelerated $\widetilde { \mathcal { O } } ( 1 / T ^ { 2 } )$ bound on the final loss. However, since their bound on the transition time τ grows linearly with η, their result suggests that a larger step size may prolong the unstable phase.

In contrast, for logistic regression in two dimensions, Crawshaw and Liu (2026) recently showed that, for suficiently large step sizes, the number of iterations τ required to enter the stable region is bounded independently of η. In addition, they showed that any target loss value ε can be reached within a fixed number of iterations, independent of ε, by taking η suficiently large. Thus, higher accuracy is obtained by increasing the step size rather than the number of iterations.

We show that these phenomena extend to multiclass logistic regression in all dimensions. Specifically, let $K \geq 2$ be the number of classes and consider a dataset $\{ ( x _ { i } , y _ { i } ) \} _ { i = 1 } ^ { n } ,$ where $x _ { i } \in \mathbb { R } ^ { d }$ and $y _ { i } \in \{ 1 , \ldots , K \}$ . We consider a linear softmax classifier parameterized by $\dot { W } \in \mathbb { R } ^ { K \times d }$ , whose kth row is denoted by $w _ { k } \in \mathbb { R } ^ { d }$ . The associated multiclass cross-entropy loss is

$$
f ( W ) : = - \frac { 1 } { n } \sum _ { i = 1 } ^ { n } \sum _ { k = 1 } ^ { K } Y _ { i k } \log \bigl ( P ( W ) _ { i k } \bigr ) , \qquad P ( W ) _ { i k } : = \frac { \exp \bigl ( \langle w _ { k } , x _ { i } \rangle \bigr ) } { \sum _ { j = 1 } ^ { K } \exp \bigl ( \langle w _ { j } , x _ { i } \rangle \bigr ) } .\tag{1}
$$

Here, $\langle w _ { k } , x _ { i } \rangle$ represents the score of class k for data point $x _ { i } .$ and $P ( W ) \in \mathbb { R } ^ { n \times K }$ is the matrix of row-wise softmax probabilities. Lastly, $Y \in \mathbb { R } ^ { n \times K }$ is the one-hot encoding of the labels, that is,

$$
Y _ { i y _ { i } } = 1 , \qquad { \mathrm { a n d } } \qquad Y _ { i k } = 0 { \mathrm { ~ f o r ~ a l l ~ } } k \neq y _ { i } .\tag{2}
$$

We assume that the dataset is linearly separable and consider full-batch GD on $f$ with constant step size $\eta > 0$ , whose sequence of iterates $\{ W ^ { ( t ) } \} _ { t \geq 0 }$ is generated by the update rule

$$
\boldsymbol { W } ^ { ( t + 1 ) } = \boldsymbol { W } ^ { ( t ) } - \eta \nabla \boldsymbol { f } ( \boldsymbol { W } ^ { ( t ) } ) ,
$$

initialized at $W ^ { ( 0 ) } = 0$

## 1.1 Main results

We establish two complementary convergence guarantees for multiclass GD with large step sizes. The first gives a two-phase convergence result in which the transition time grows at most linearly with the step size. The second shows that, once the step size is larger than a data-dependent threshold, this dependence disappears and the transition occurs within a fixed number of iterations.

We now introduce the assumptions and notation needed to state these results precisely. Throughout, we define $[ n ] = \{ 1 , \dots , n \}$ and we use $\langle \cdot , \cdot \rangle$ and $\langle \cdot , \cdot \rangle _ { \mathrm { F } }$ for the standard Euclidean inner products on $\mathbb { R } ^ { d }$ and $\mathbb { R } ^ { K \times d }$ , respectively, and $\| \cdot \|$ and $\Vert \cdot \Vert _ { \mathrm { F } }$ for the associated norms. We assume that the data satisfy the following:

(A1) $\| x _ { i } \| \leq 1$ for all $i \in \left[ n \right]$

(A2) There exist $W ^ { \ast } \in \mathbb { R } ^ { K \times d }$ and $\gamma > 0$ such that $\Vert W ^ { * } \Vert _ { \mathrm { F } } \leq 1$ and

$$
\begin{array} { r } { \big \langle w _ { y _ { i } } ^ { * } , x _ { i } \big \rangle \geq \big \langle w _ { k } ^ { * } , x _ { i } \big \rangle + \gamma \qquad \mathrm { ~ f o r ~ a l l ~ } i \in [ n ] \mathrm { ~ a n d ~ a l l ~ } k \neq y _ { i } . } \end{array}
$$

The assumptions are standard: (A2) requires the data to be linearly separable with positive margin, while the bounds $\| x _ { i } \| \leq 1$ and $\| W ^ { * } \| _ { \mathrm { F } } \leq 1$ merely fix the scale of the problem and are without loss of generality. Note that the margin $\gamma$ need not be maximal: defining

$$
\gamma _ { \operatorname* { m a x } } : = \operatorname* { m a x } _ { \| W \| _ { \mathrm { F } } \leq 1 } \operatorname* { m i n } _ { i \in [ n ] } \operatorname* { m i n } _ { k \neq y _ { i } } \langle w _ { y _ { i } } - w _ { k } , x _ { i } \rangle ,\tag{3}
$$

our results hold for any admissible $\gamma .$ , and in particular with $\gamma = \gamma _ { \mathrm { m a x } }$

Remark 1.1. For $K \ : = \ : 2$ , the multiclass problem reduces to binary logistic regression under the identification $w = w _ { 1 } - w _ { 2 }$ , with $f ( W ) = f _ { \mathrm { b i n } } ( w ) , \eta _ { \mathrm { b i n } } = 2 \eta$ , and $\gamma _ { \mathrm { b i n } } = \gamma _ { \mathrm { m a x } } / \sqrt { 2 }$ (see Appendix $A )$ .

For GD with step size $\eta ,$ we define the stable region as the set where $f ( W ) < 1 / ( 2 \eta )$ , a threshold below which we obtain monotonic descent at every subsequent iteration (Lemma C.3). To quantify when the iterates enter this phase, we introduce the transition time

$$
\tau : = \operatorname* { i n f } \left. t \geq 0 \bigg | f ( W ^ { ( t ) } ) < \frac { 1 } { 2 \eta } \right. ,\tag{4}
$$

with the convention that inf $\mathcal { D } = + \infty$

We now state informal versions of our main results, suppressing constants and technical conditions on the step size. The first result extends the two-phase convergence analysis of GD on the logistic regression loss by Wu et al. (2024) from the binary to the multiclass setting. The proof, however, is diferent: it relies on a multiclass perceptron inequality (Lemma 3.1) and yields a $\mathcal { O } ( 1 / T ^ { 2 } )$ last-iterate rate, avoiding the additional logarithmic factors in (Wu et al., 2024, Cor. 2). The corresponding quantitative statements are given in Theorem 4.1 and Corollary 4.2.

Theorem 1.2. (informal) Run GD with constant step size $\begin{array} { r } { \eta \geq \frac { n } { 2 } } \end{array}$ on $f \ ( 1 )$ , initialized at $W ^ { ( 0 ) } = 0$ As defined, the iterates enter the stable region $\{ W \mid f ( W ) < 1 / 2 \eta \}$ after τ (4) iterations. Then:

(i) (Transition time.) The transition time τ satisfies $\begin{array} { r } { \tau \leq \mathcal { O } ( \frac { \eta + \log ( \eta K ) } { \gamma ^ { 2 } } ) } \end{array}$

(ii) (Loss decrease in the stable region.) For all $t > \tau _ { \mathrm { : } }$ , the iterates remain in the stable region and the loss satisfies $\begin{array} { r } { f ( W ^ { ( t ) } ) = \mathcal { O } \left( \frac { 1 } { \eta \gamma ^ { 2 } ( t - \tau ) } \right) } \end{array}$

Theorem 1.2 highlights a trade-of: increasing the step size may linearly increase the time required to enter the stable region, but reduces the loss bound once it is there. Balancing these two efects by choosing η in terms of the iteration budget T gives the following accelerated rate for the last iterate.

Corollary 1.3. Assume that the iteration budget satisfies $T \gtrsim \frac { n + \log K } { \gamma ^ { 2 } }$ , and run GD with a suitable constant step size $\eta = \Theta ( \gamma ^ { 2 } T )$ . Then, the iterates enter the stable region within the first half of the iteration budget, that is, $\begin{array} { r } { \tau \leq \frac { T } { 2 } } \end{array}$ , and the loss at iteration T satisfies $\begin{array} { r } { f ( W ^ { ( T ) } ) = \mathcal { O } \left( \frac { 1 } { \gamma ^ { 4 } T ^ { 2 } } \right) } \end{array}$

Theorem 1.2 shows that the transition time grows at most linearly with η. In fact, once the step size is suficiently large, it becomes independent of η (even though the stable region keeps shrinking). For similar reasons (and surprisingly to us), by increasing the step size, we can make the loss arbitrarily small in a number of iterations that is independent of the target loss.

Theorem 1.4. (informal) Fix a dataset $\{ ( x _ { i } , y _ { i } ) \} _ { i = 1 } ^ { n }$ satisfying (A1) and (A2). There exist a constant $\delta > 0$ and an iteration count $T \leq \lfloor 4 n / \gamma ^ { 2 } \rfloor + 1$ (that depend only on this dataset) such that, if we optimize $f$ in (1) using GD initialized at $W ^ { ( 0 ) } = 0$ with any constant step size η, then

(i) (Transition time.) There exists a threshold $\eta _ { \mathrm { t r } } ^ { * } = \eta _ { \mathrm { t r } } ^ { * } ( \delta , T , K )$ such that, $i f \eta \geq \eta _ { \mathrm { t r } } ^ { * }$ , the iterates enter the stable region in $\tau \leq T$ iterations.

(ii) (ε-loss at a fixed iteration T independent of η and $\varepsilon . /$ For any $\varepsilon \in ( 0 , 1 )$ , there exists a threshold $\eta _ { \varepsilon } ^ { * } = \eta _ { \varepsilon } ^ { * } ( \delta , T , K , \varepsilon )$ such that, if $\eta \geq \eta _ { \varepsilon } ^ { * }$ , then $f ( W ^ { ( T ) } ) < \varepsilon$

For binary logistic regression in two dimensions $( K = 2 , d = 2 )$ ), Crawshaw and Liu (2026) showed a similar result, but with uniform step size thresholds depending only on the coarser dataset parameters n and γ. Specifically, they showed that there exist $\eta _ { 0 } ( n , \gamma )$ and $T ( n , \gamma )$ such that GD with any step size $\eta \ge \eta _ { 0 } ( n , \gamma )$ on any dataset with n samples and margin γ enters the stable region after $\tau \leq T ( n , \gamma )$ iterations. In Theorem 5.2, we further show that such a uniform result does not extend to higher dimensions. This justifies the appearance of a new data-dependent constant such as $\delta .$

Unlike Crawshaw and Liu (2026), whose analysis relies on the region outside the stable one being disconnected (which holds only for $d = 2 )$ , our proof relies on taking $\eta  \infty$ . As already identified by Tyurin (2025) in the binary case, taking $\eta  \infty$ produces a well-defined limiting dynamical system, namely, a batched multiclass hard perceptron (HP). Using the perceptron inequality (Lemma 3.1), we show that the (HP) dynamics produce a perfect classifier after $\bar { T } \le \left\lfloor \bar { 4 n } / \gamma ^ { 2 } \right\rfloor + 1$ steps, and subsequently terminates. Then, for every fixed dataset, we quantitatively show that once the step size exceeds a data-dependent threshold, the rescaled GD iterates closely track the corresponding perceptron iterates up to time T. In particular, this implies that the T-th iterate of GD is also a perfect classifier, which ultimately implies a bound on $f ( W ^ { ( T ) } )$ that decays exponentially in η (Proposition 5.8). This is the key ingredient for both statements of Theorem 1.4.

Remark 1.5. Theorems 1.2 and 1.4 describe diferent large step size regimes. Corollary 1.3 gives an explicit $\mathcal { O } ( 1 / T ^ { 2 } )$ guarantee by choosing the step size η as a function of the iteration budget T, whereas Theorem 1.4 shows that, beyond a data-dependent threshold, the transition time itself becomes independent of the step size. Thus, neither result subsumes the other.

## 1.2 Proof ideas

To analyze gradient descent with large step sizes, we draw on its close resemblance to the perceptron algorithm (Rosenblatt, 1958; Novikof, 1962). In Section 3, we introduce a general batched perceptron dynamics (GBPD). Using its update rule $Z ^ { ( t + 1 ) } = Z ^ { ( t ) } + \Delta ^ { ( t ) }$ (with $\Delta ^ { ( t ) }$ specified in Section 3), we bound the progress of the alignment $\langle Z ^ { ( t ) } , W ^ { * } \rangle _ { \mathrm { F } }$ from below (Lemma 3.3), and the iterate norm $\| Z ^ { ( t ) } \| _ { \mathrm { F } }$ from above (Lemma 3.4). Both estimates depend on the cumulative average mistake mass up to time t (defined in Eq. (5)). Combining these bounds with the Cauchy–Schwarz inequality gives the main perceptron inequality (Lemma 3.1), which we use for both of our main results.

To study the GD trajectory for large step sizes η and ultimately take the limit $\eta  \infty$ , we must normalize the iterates. We therefore introduce the rescaled variables $Z ^ { ( t ) } = W ^ { ( t ) } / \eta .$ . After this change of variables, GD takes the form of the soft perceptron dynamics $( \mathrm { S P } _ { \eta } )$ , an instance of the general system (GBPD). Specializing the main perceptron inequality (Lemma 3.1) to this soft perceptron yields the refined inequality of Lemma 4.3, which bounds the cumulative average mistake mass along the trajectory.

To turn this inequality into a bound on the transition time $\tau ,$ we adapt the standard perceptron argument (Section 5.1). Instead of evaluating the perceptron inequality at the first perfect classifier iterate, we evaluate it at the first time τ at which the dynamics enters the stable region as in (4). The definition of τ then gives a lower bound on the mistake mass accumulated before time τ, which, combined with the refined perceptron inequality, yields $\tau = \mathcal { O } ( \eta )$ . The remainder of the analysis then follows standard arguments (Wu et al., 2024; Crawshaw and Liu, 2026): once the dynamics enters the stable region, the loss decreases at every subsequent iteration.

For our second result, we study the rescaled dynamics in the limit $\eta  \infty$ . Crucially, this limiting iteration map is well defined: the row-wise softmax becomes a row-wise hardmax that splits mass uniformly among classes with maximal score (Lemma 5.4). The limiting dynamics is a multiclass hard perceptron dynamics (HP), and the standard argument above gives a finite termination time $T = \bar { \mathcal { O } } \left( n / \gamma ^ { 2 } \right)$ at which it reaches a perfect classifier.

To transfer this conclusion to GD, we show that the soft perceptron $( \mathrm { S P } _ { \eta } )$ shadows the hard perceptron (HP) trajectory up to time T if the step size is large enough. The required step size depends on the smallest positive gap δ between a maximal and a nonmaximal score encountered along the (HP) trajectory (defined in $\mathrm { E q . ~ ( 2 1 ) } )$ . This gap is positive because only finitely many iterates and class scores are involved. An induction on t shows that, up to time T, the $( \mathrm { S P } _ { \eta } )$ scores remain close to the (HP) ones, which in particular implies that GD also produces a perfect classifier at time T. Additionally, the same argument yields a bound on the loss that decays exponentially in $\eta ,$ giving both the bound on the transition time $\tau \leq T$ and, after increasing η if necessary, $f ( W ^ { ( T ) } ) < \varepsilon$ for any prescribed $\varepsilon > 0$

## 2 Related work

Optimization with large step sizes. Classical analyses of gradient descent typically impose a condition on the step size that guarantees a decrease in the objective at every iteration. Nevertheless, empirical studies have shown that GD can still converge despite this nonmonotonic behavior (Smith and Topin, 2019; Lewkowycz et al., 2020; Cohen et al., 2021). More recent theoretical work has established convergence in several such unstable regions and has proposed mechanisms including progressive sharpening, self-stabilization, and the interaction between successive gradient descent steps (Ahn et al., 2022; Arora et al., 2022; Damian et al., 2022; Chen and Bruna, 2023).

A distinct line of work considers non-constant step size schedules that contain occasional long steps. Although such steps need not decrease the objective individually, their cumulative efect can accelerate gradient descent on smooth convex problems. Examples include fractal step size schedules (Agarwal et al., 2021), long-step schedules (Grimmer, 2024; Grimmer et al., 2025), the silver step size schedule of Altschuler and Parrilo (2025) and schedules involving restarts (Cl´ement and Steinerberger, 2026).

Binary logistic regression with large step sizes. For linearly separable logistic regression, Wu et al. (2023) proved that, for any constant step size, the loss converges to zero and the iterates converge in direction to the maximum-margin separator. Subsequently, Wu et al. (2024) showed that large step sizes can improve the convergence rate: after an initial nonmonotone phase of at most $\mathcal { O } ( \eta )$ iterations, gradient descent enters a region in which the loss decreases at each step. In two dimensions, Crawshaw and Liu (2026) showed that, for any η large enough, the length of this initial unstable phase is in fact independent of η. Concurrent works have further refined this picture: Gong and Li (2026) showed that the transition time is upper bounded by an expression polylogarithmic in η, while Wen et al. (2026) showed that a similar polylogarithmic dependence in η is tight in the worst case.

The connection with perceptron dynamics was studied by Tyurin (2025), who showed that, for binary logistic regression, rescaled GD converges to a batch perceptron as the step size tends to infinity, and analyzed the resulting iteration complexity for finding a separating classifier. Extensions to this phenomenon include regularized logistic regression (Wu et al., 2026), local gradient descent on heterogeneous data (Crawshaw et al., 2025), and more general Fenchel–Young losses (Bao et al., 2026). For nonseparable data, however, GD with large step sizes on the logistic regression problem can converge to stable periodic orbits (Meng et al., 2024). A separate line of work considers adaptive or increasing step sizes for separable logistic regression (Axiotis and Sviridenko, 2023; Zhang et al., 2025; Kale et al., 2026).

Multiclass logistic regression with large step sizes. For separable multiclass data, Soudry et al. (2018) and Ravi et al. (2024) showed that, for a suficiently small fixed step size, the GD iterates converge in direction to the multiclass maximum-margin solution. Emmanouilidis et al. (2026) study multiclass cross-entropy with arbitrary constant step sizes for minibatch SGD. They prove an expected best-iterate convergence guarantee of order $\widetilde { \cal O } ( ( 1 + \eta ^ { 2 } ) / ( \gamma ^ { 2 } \eta t ) )$ , extending the corresponding binary result for SGD from (Wu et al., 2024, Thm. 4). Additionally, they develop a stochastic notion of stability under which the iterates enter a stable loss sublevel with high probability and subsequently return to it after stochastic excursions. Their bound on the time to first enter the stable region grows linearly with the step size. Our results instead concern deterministic full-batch GD: in the first part, we obtain an explicit $\mathcal { O } ( \eta / \gamma ^ { 2 } )$ bound on the transition time, and subsequently show that, for suficiently large step sizes, there is no dependence on η.

Perceptrons. The perceptron was introduced by Rosenblatt (1958), and its finite convergence on linearly separable data was proved by Novikof (1962). The standard algorithm is online, while batch variants aggregate the corrections from all currently misclassified examples (Haykin, 2009, §1.6). For multiclass classification, Crammer and Singer (2003) analyzed online perceptron-type algorithms and proved margin-dependent mistake bounds under linear separability.

A connection between large-step GD and batch perceptron dynamics was established by Tyurin (2025) for binary logistic regression: as the step size tends to infinity, the rescaled GD iterates converge to those of a batch perceptron. Our $\eta  \infty$ dynamics (HP) extends this connection to multiclass cross-entropy. In our case, the limiting dynamics is a full-batch multiclass perceptron that sums the corrections over all training examples, with the correction for each example divided equally among all classes with the largest score. Additionally, we make this connection quantitative for finite step sizes: for suficiently large $\eta ,$ the GD iterates shadow the multiclass perceptron dynamics up to its termination time. Under suitable conditions on the step size, at this same iteration GD has either entered the stable region or achieved loss below any prescribed $\varepsilon > 0$

In their work showing convergence for GD on Fenchel-Young losses with any step size, Bao et al. (2026) also use a perceptron-type inequality, but for the original GD iterates $w _ { t }$ rather than for rescaled iterates. Their lower bound on $\langle w _ { t } , w ^ { * } \rangle$ is obtained by recursively expanding the GD update (similar to our Lemma 3.3), and they use the split optimization technique from (Wu et al., 2024) for upper bounding $\lVert \boldsymbol { w } _ { t } \rVert$ . In contrast, our proofs do not use this technique: see Lemma 3.4.

## 3 A general perceptron-like dynamical system

The proofs of our main results build on perceptron-type arguments. To isolate the parts of these arguments that we will reuse later, we first introduce a more general dynamical system.

Let $\boldsymbol { X } \in \mathbb { R } ^ { n \times d }$ be the matrix with rows $x _ { i } ^ { \top }$ , and $Y \in \mathbb { R } ^ { n \times K }$ the one-hot label matrix as in (2). Consider a map $\Pi \colon \mathbb { R } ^ { K \times d }  \mathbb { R } ^ { n \times K }$ (which may depend on $X )$ such that for all $i \in [ n ]$ and $k \in [ K ]$

$$
\Pi ( Z ) _ { i k } \geq 0 \qquad \mathrm { a n d } \qquad \sum _ { k = 1 } ^ { K } \Pi ( Z ) _ { i k } = 1 .
$$

That is, each row $\Pi ( Z ) _ { i }$ is a probability vector over the K classes: $\Pi ( Z ) _ { i y _ { i } }$ is the mass assigned to the correct class, while $\begin{array} { r } { \sum _ { k \neq y _ { i } } \Pi ( Z ) _ { i k } = 1 - \Pi ( Z ) _ { i y _ { i } } } \end{array}$ is the total mass assigned to the other (incorrect) classes. Next, we define the map $H \colon \mathbb { R } ^ { K \times d } \to \mathbb { R } ^ { n \times K }$ as

$$
H ( Z ) : = { \frac { 1 } { n } } { \big ( } Y - \Pi ( Z ) { \big ) } .
$$

The i-th row of $H ( Z )$ compares the true label of the i-th data point with the probability vector $\Pi ( Z ) _ { i }$ <sub>i</sub>. Throughout this section, we study the following general batched perceptron dynamics:

$$
\boldsymbol { Z } ^ { ( t + 1 ) } = \boldsymbol { Z } ^ { ( t ) } + \boldsymbol { H } ( \boldsymbol { Z } ^ { ( t ) } ) ^ { \top } \boldsymbol { X } , \qquad \boldsymbol { Z } ^ { ( 0 ) } = \boldsymbol { 0 } \in \mathbb { R } ^ { K \times d } .\tag{GBPD}
$$

Each update is a linear combination of the data points, weighted by the diference between the true labels $Y$ and the predicted probability vectors $\Pi ( Z ^ { ( t ) } )$ , hence the connection to the perceptron. Unlike the original online perceptron, which updates using one data point at a time, (GBPD) aggregates the contributions of all data points in each iteration.

For any $Z \in \mathbb { R } ^ { K \times d }$ , define the average mistake mass as

$$
S ( Z ) : = \frac { 1 } { n K } \sum _ { i = 1 } ^ { n } \sum _ { k \in [ K ] , k \neq y _ { i } } \Pi ( Z ) _ { i k } = \frac { 1 } { n K } \sum _ { i = 1 } ^ { n } ( 1 - \Pi ( Z ) _ { i y _ { i } } ) .\tag{5}
$$

Along the trajectory of (GBPD), we write $S ^ { ( t ) } : = S ( Z ^ { ( t ) } )$ when convenient.

The next lemma gives the perceptron inequality for this system. We will later apply it for two particular choices of Π. In both cases, after further bounding the second term on the left-hand side, we obtain an upper bound on the cumulative average mistake mass $\textstyle \sum _ { t = 0 } ^ { T - 1 } S ( Z ^ { ( t ) } )$

Lemma 3.1. Let $( Z ^ { ( t ) } ) _ { t \geq 0 }$ be the trajectory of (GBPD). Under $( A I )$ and (A2), we have

$$
2 K \sum _ { t = 0 } ^ { T - 1 } S ( Z ^ { ( t ) } ) + 2 \sum _ { t = 0 } ^ { T - 1 } \langle Z ^ { ( t ) } , H ( Z ^ { ( t ) } ) ^ { \top } X \rangle _ { \mathrm { F } } \geq \gamma ^ { 2 } K ^ { 2 } \left( \sum _ { t = 0 } ^ { T - 1 } S ( Z ^ { ( t ) } ) \right) ^ { 2 } \quad \ f o r \ a l l \ T \geq 1 .
$$

The rest of this section is devoted to the proof of Lemma 3.1. The argument follows the standard perceptron strategy (Novikof, 1962): by recursively unrolling the (GBPD) update rule, we first lower bound the inner product of the iterate with the separating matrix $W ^ { * }$ (Lemma 3.3), and then upper bound the growth of $\| Z ^ { ( T ) } \| _ { \mathrm { F } }$ (Lemma 3.4). The perceptron inequality then follows by combining these two estimates with the Cauchy–Schwarz inequality.

The next lemma shows that each update makes some progress in the direction of $W ^ { * }$

Lemma 3.2. Under (A2), the following holds:

$$
\langle W ^ { * } , H ( Z ) ^ { \top } X \rangle _ { \mathrm { F } } \geq \gamma K S ( Z ) .
$$

Proof. Using $\begin{array} { r } { H ( Z ) = \frac { 1 } { n } ( Y - \Pi ( Z ) ) } \end{array}$ , we rewrite

$$
\langle W ^ { * } , H ( Z ) ^ { \top } X \rangle _ { \mathrm { F } } = \sum _ { k = 1 } ^ { K } \sum _ { i = 1 } ^ { n } \langle w _ { k } ^ { * } , x _ { i } \rangle ( H ( Z ) ^ { \top } ) _ { k i } = \frac { 1 } { n } \sum _ { k = 1 } ^ { K } \sum _ { i = 1 } ^ { n } \langle w _ { k } ^ { * } , x _ { i } \rangle \left( Y _ { i k } - \Pi _ { i k } \right) ,\tag{6}
$$

where we used the notation $\Pi = \Pi ( Z )$ , since there is no risk of confusion. Recall from Eq. (2) that $Y _ { i k } = 1 { \mathrm { ~ i f ~ } } k = y _ { i }$ and $Y _ { i k } = 0$ otherwise. ## 4.1 Rescaled dynamics: the soft perceptron

Fix a step size $\eta > 0$ and consider the GD iterates $W ^ { ( t ) }$ optimizing the loss $f$ as in (1), initialized at $W ^ { ( 0 ) } = 0 \bar { }$ . A direct computation (Appendix B) shows that the GD update takes the matrix form

$$
\boldsymbol { W } ^ { ( t + 1 ) } = \boldsymbol { W } ^ { ( t ) } + \frac { \eta } { n } \big ( \boldsymbol { Y } - \boldsymbol { P } ( \boldsymbol { W } ^ { ( t ) } ) \big ) ^ { \top } \boldsymbol { X } .\tag{10}
$$

To apply the general perceptron argument from Section 3, we define the rescaled iterates

$$
Z ^ { ( t ) } : = \frac { 1 } { \eta } W ^ { ( t ) } .
$$

Dividing the GD update (10) by $\eta \textrm { y }$ ields the following update rule for $Z ^ { ( t ) }$ :

$$
Z ^ { ( t + 1 ) } = Z ^ { ( t ) } + \frac { 1 } { n } \bigl ( Y - P ( \eta Z ^ { ( t ) } ) \bigr ) ^ { \top } X , \qquad Z ^ { ( 0 ) } = 0 .\tag{SP<sub>η</sub>}
$$

We call $( \mathrm { S P } _ { \eta } )$ the soft perceptron dynamics. Observe that this corresponds to (GBPD) with

$$
\Pi ( Z ) = P ( \eta Z ) , \qquad \mathrm { a n d } \qquad H ( Z ) = \frac { 1 } { n } \big ( Y - P ( \eta Z ) \big ) .
$$

For this choice of Π, the average mistake mass at iteration t is the total softmax probability assigned to the incorrect classes, which we denote by

$$
S ^ { ( t ) } : = S ( Z ^ { ( t ) } ) = \frac { 1 } { n K } \sum _ { \substack { i = 1 } } ^ { n } \sum _ { \substack { k \in [ K ] , k \neq y _ { i } } } P ( \eta Z ^ { ( t ) } ) _ { i k }\tag{11}
$$

\frac { 1 } { n } \sum _ { i = 1 } ^ { n } \mathsf { E n t } ( P _ { i } ) \leq h ( K S ( Z ) ) + \log ( K - 1 ) \frac { 1 } { n } \sum _ { i = 1 } ^ { n } m _ { i }\tag{15}
$$

To obtain the final result, it remains to bound $h ( K S ( Z ) )$ ). Using that $- ( 1 - p ) \log ( 1 - p ) \leq p$ for all $p \in [ 0 , 1 ]$ , we obtain

$$
h ( p ) = - p \log ( p ) - ( 1 - p ) \log ( 1 - p ) \leq - p \log ( p ) + p = p \log \left( { \frac { e } { p } } \right) .
$$

Taking $p = K S ( Z ) \in [ 0 , 1 ]$ and plugging the result back in Eq. (15), we conclude

$$
{ \frac { 1 } { n } } \sum _ { i = 1 } ^ { n } \mathsf { E n t } ( P _ { i } ) \leq K S ( Z ) \log \left( { \frac { e ( K - 1 ) } { K S ( Z ) } } \right) .
$$

This proves Lemma 4.5.

We can now combine these results to prove Lemma 4.3.

Proof of Lemma $4 . 3 .$ . Applying Lemma 3.1 with $\Pi ( Z ) = P ( \eta Z )$ gives

$$
2 K \sum _ { t = 0 } ^ { T - 1 } S ^ { ( t ) } + 2 \sum _ { t = 0 } ^ { T - 1 } \langle Z ^ { ( t ) } , H ( Z ^ { ( t ) } ) ^ { \top } X \rangle _ { \mathrm { F } } \geq \gamma ^ { 2 } K ^ { 2 } \left( \sum _ { t = 0 } ^ { T - 1 } S ^ { ( t ) } \right) ^ { 2 } .

$$

Substituting this bound into the previous inequality and dividing by K gives the result. □

## 4.3 Transition to the stable region

We now prove the first part of Theorem 4.1. The key ingredient is a lower bound on the average mistake mass $S ^ { ( t ) }$ while the iterates are in the unstable region. Combined with Lemma 4.3, this yields an upper bound on the length of the unstable phase.

We begin with a general lower bound on the average mistake mass in terms of the loss. The result is the multiclass analogue of Lemma C.1 in (Crawshaw and Liu, 2026), although our proof uses a diferent argument.

Lemma 4.6. For every $Z \in \mathbb { R } ^ { K \times d }$ , the average mistake mass $\left( E q . \ ( 1 1 ) \right)$ satisfies

$$

$$

where the last step follows from Eq. (16)

## 4.4 Loss decay in the stable region

This section proves part (ii) of Theorem 4.1, following the argument from the proof of Theorem 2.1 in Crawshaw and Liu (2026).

By definition, $W ^ { ( \tau ) }$ is in the stable region. By Lemma B.4, it holds that $\nabla ^ { 2 } f ( W ) \preceq 2 f ( W ) I$ for all W. Then, Lemma C.3 gives that the stable region is forward invariant and that, for all $t \geq \tau$

$$

## 5 Step-size-independent transition time

The goal of this section is to prove a quantitative version of Theorem 1.4. We do so by comparing the soft perceptron dynamics $( \mathrm { S P } _ { \eta } )$ with a dynamical system obtained by taking $\eta  \infty$ . In Section 5.1, we show that this limit is indeed well defined and is given by the following hard perceptron dynamics:

$$
\tilde { Z } ^ { ( t + 1 ) } = \tilde { Z } ^ { ( t ) } + \frac { 1 } { n } \big ( Y - Q ( \tilde { Z } ^ { ( t ) } ) \big ) ^ { \top } X , \qquad \tilde { Z } ^ { ( 0 ) } = 0 ,\tag{HP}
$$

where $Q \colon \mathbb { R } ^ { K \times d }  \mathbb { R } ^ { n \times K }$ is a row-hardmax operation given by

$$
Q ( Z ) _ { i k } = \left( { \mathrm { h a r d m a x } } ( Z x _ { i } ) \right) _ { k } , \quad { \mathrm { ~ w i t h ~ } } \quad \left( { \mathrm { h a r d m a x } } ( s ) \right) _ { k } : = { \frac { \mathbb { 1 } _ { \{ k \in \operatorname { a r g m a x } _ { \ell \in \{ 1 , \ldots , K \} } \} } } { \left| \operatorname * { a r g m a x } _ { \ell \in \{ 1 , \ldots , K \} } \right| } } .\tag{18}
$$

We call a matrix $\boldsymbol { Z } \in \mathbb { R } ^ { K \times d } \mathrm { ~ a ~ }$ perfect classifier if, for every training example, the correct class has a strictly larger inner product with the input than every incorrect class:

$$
\langle z _ { y _ { i } } , x _ { i } \rangle > \langle z _ { k } , x _ { i } \rangle
$$

$$
{ \mathrm { f o r ~ a l l ~ } } i \in [ n ] { \mathrm { ~ a n d ~ a l l ~ } } k \neq y _ { i } .\tag{19}
$$

If an iterate Z is a perfect classifier, then $Q ( Z ) = Y$ and so the hard perceptron dynamics terminate. In Lemma 5.5, we show that the hard perceptron dynamics (HP) reach a perfect classifier after

$$
T \leq \left\lfloor { \frac { 4 n } { \gamma ^ { 2 } } } \right\rfloor + 1\tag{20}
$$

iterations. This is a batch analogue of the classical convergence guarantees for the online multiclass perceptron (Crammer and Singer, 2003). In Section 5.2, we then show that for suficiently large η, the soft perceptron trajectory “shadows” the limiting trajectory up to this time. More specifically, the finite-η scores $s _ { i k } ^ { ( t ) } : = \langle z _ { k } ^ { ( t ) } , x _ { i } \rangle$ remain close enough to the limiting scores $\tilde { s } _ { i k } ^ { ( t ) } : = \langle \tilde { z } _ { k } ^ { ( t ) } , \bar { x } _ { i } \rangle$ . Define the set of “winner” classes (attaining the largest limiting score) by

$$
\widetilde { \mathcal { W } } _ { i } ^ { ( t ) } : = \underset { k \in [ K ] } { \mathrm { a r g m a x } } \ \widetilde { s } _ { i k } ^ { ( t ) } .
$$

We then define the smallest positive gap between a maximizing and a nonmaximizing class along the first T limiting iterates as

$$
\delta : = \operatorname* { m i n } \left. \widetilde { s } _ { i \ell } ^ { ( t ) } - \widetilde { s } _ { i k } ^ { ( t ) } \ \middle \vert \ 0 \leq t \leq T , \ i \in [ n ] , \ \ell \in \widetilde { \mathcal { W } } _ { i } ^ { ( t ) } , \ k \notin \widetilde { \mathcal { W } } _ { i } ^ { ( t ) } \right. .\tag{21}
$$

The minimum is taken over a finite, nonempty set of positive values, and therefore $\delta > 0$ . Moreover, observe that δ is determined entirely by the (HP) trajectory, and therefore depends only on the data X and labels Y. In particular, it is independent of the GD step size η.

Although the shadowing result controls the soft perceptron dynamics only up to time T, choosing a suficiently large η ensures that, by this time, the iterates have already entered the stable region, despite the fact that the stable sublevel set shrinks as η grows. Alternatively, for any prescribed $\varepsilon > 0 ,$ the step size can be chosen so that the loss at time $T$ is at most ε. The following theorem makes these statements precise.

Theorem 5.1. Fix a dataset $\{ ( x _ { i } , y _ { i } ) \} _ { i = 1 } ^ { n }$ satisfying (A1) and (A2). Let T be the termination time of the hard perceptron (HP) on this dataset (well defined by Lemma $5 . 5 )$ , and let $\delta > 0$ be the gap defined in (21). $D e f i n e \ r : = \operatorname* { m a x } \{ 1 , T / \delta \}$ . If we optimize the loss f as in (1) using GD initialized at $W ^ { ( 0 ) } = 0$ with constant step size $\eta > 0$ , then:

(i) (Transition time.) If

$$
\eta \geq \operatorname* { m a x } \left\{ 2 r \log \left( 2 r \log ( 2 r ) \right) , \frac { 8 ( K - 1 ) } { \delta } , \frac { 4 } { \delta } \log \left( \frac { 4 ( K - 1 ) } { \delta } \right) \right\} ,
$$

then the transition time τ to the stable region (4) satisfies

$$
\tau \leq T \leq \left\lfloor { \frac { 4 n } { \gamma ^ { 2 } } } \right\rfloor + 1 .
$$

(ii) (ε-loss at a fixed iteration T independent of η and $\varepsilon . \big )$ For any $\varepsilon \in ( 0 , 1 )$ , if

$$
\eta \geq \operatorname* { m a x } \left. 2 r \log \left( 2 r \log ( 2 r ) \right) , \frac { 8 ( K - 1 ) } { \delta } , \frac 2 \delta \log \left( \frac { K - 1 } { \varepsilon } \right) \right. ,
$$

then $f ( W ^ { ( T ) } ) < \varepsilon$

The theorem shows, in particular, that GD can reach ε-loss in a number of iterations that is independent of ε (only the required step size depends on ε).

While the dependence of the step size threshold on n and γ is expected (Crawshaw and Liu, 2026), a natural question is whether the new dependency on δ in Theorem 5.1 is strictly necessary, or if this could be replaced by a uniform threshold depending only on the coarser dataset parameters n and γ. A counterexample shows that this is impossible already in dimension three. Moreover, the same construction shows that the dependence on δ in Theorem 5.1 is essentially sharp.

Theorem 5.2. For every $N \geq 1$ , there exists $\eta _ { N } > 0$ such that, for every $\eta \geq \eta _ { N }$ , there exists a linearly separable dataset $X _ { \eta }$ with $K = 2$ consisting of three points in $\mathbb { R } ^ { 3 }$ , each of norm at most 1 and with margin at least $1 / \sqrt { 2 6 }$ , for which GD initialized at zero with step size η requires more than N iterations to enter the stable region.

2. For every fixed $c \in ( 0 , 1 )$ and large enough η, GD initialized at zero with step size $\begin{array} { r } { c \frac { 1 } { \delta _ { \eta } } \log \left( \frac { 2 } { \delta _ { \eta } } \right) } \end{array}$ does not enter the stable region within $T = 1$ iteration.

3. For every $\varepsilon \in ( 0 , \frac { 1 } { 6 } )$ and large enough η, GD initialized at zero with any step size smaller than $\begin{array} { r } { \frac { 1 } { \delta _ { \eta } } \log \left( \frac { 1 } { 6 \varepsilon } \right) } \end{array}$ does not achieve loss below ε at iteration $T = 1$

## 5.1 The hard perceptron dynamics

In the first part of this section, we show that the hard perceptron dynamics (HP) is obtained by taking the limit $\eta  \infty$ in the soft perceptron dynamics $( \mathrm { S P } _ { \eta } )$

Lemma 5.4. Consider the $( \mathrm { S P } _ { \eta } )$ and (HP) iteration maps given by

$$

The next lemma shows that the hard perceptron dynamics reaches a perfect classifier in finite time, with an explicit bound on the number of iterations. This is a full-batch multiclass analogue of the classical perceptron convergence theorem (Novikof, 1962); related multiclass mistake bounds were established by Crammer and Singer (2003).

Lemma 5.5. Under $( A I )$ and (A2), (HP) reaches a perfect classifier (19) in $\begin{array} { r } { T \le \left\lfloor \frac { 4 n } { \gamma ^ { 2 } } \right\rfloor + 1 } \end{array}$ iterations.

Proof. Observe that the hard perceptron dynamics (HP) is an instance of (GBPD) with $H ( Z ) =$ ${ \frac { 1 } { n } } ( Y - Q ( Z ) )$ , so we can use the results from Section 3. For this system, define the average mistake mass at iteration t as

$$
\tilde { S } ^ { ( t ) } : = S ( \tilde { Z } ^ { ( t ) } ) = \frac { 1 } { n K } \sum _ { i = 1 } ^ { n } \sum _ { k \in [ K ] , k \neq y _ { i } } Q ( \tilde { Z } ^ { ( t ) } ) _ { i k } .\tag{22}
$$

By Lemma 3.1 applied to the hard perceptron dynamics (HP), for all $T \geq 1$ we obtain

$$
2 K \sum _ { t = 0 } ^ { T - 1 } \tilde { S } ^ { ( t ) } + 2 \sum _ { t = 0 } ^ { T - 1 } \langle \tilde { Z } ^ { ( t ) } , H ( \tilde { Z } ^ { ( t ) } ) ^ { \top } X \rangle _ { \mathrm { F } } \geq \gamma ^ { 2 } K ^ { 2 } \left( \sum _ { t = 0 } ^ { T - 1 } \tilde { S } ^ { ( t ) } \right) ^ { 2 } .\tag{23}
$$

We will show that the inner product term is non-positive. We have

$$
\langle \tilde { Z } ^ { ( t ) } , H ( \tilde { Z } ^ { ( t ) } ) ^ { \top } X \rangle _ { \mathrm { F } } = \frac { 1 } { n } \langle \tilde { Z } ^ { ( t ) } , ( Y - Q ( \tilde { Z } ^ { ( t ) } ) ) ^ { \top } X \rangle _ { \mathrm { F } } = \frac { 1 } { n } \sum _ { i = 1 } ^ { n } \sum _ { k = 1 } ^ { K } \langle \tilde { z } _ { k } ^ { ( t ) } , x _ { i } \rangle \big ( Y _ { i k } - Q _ { i k } \big ) ,\tag{24}
$$

where we use $Q = Q ( \tilde { Z } ^ { ( t ) } )$ here. We argue that the contribution of each data point to the sum is non-positive. Recall that $Y _ { i k } = 1$ if $k = y _ { i }$ and $Y _ { i k } = 0$ otherwise. Also, from Eq. (18),

$$
Q _ { i k } = \frac { 1 } { \left| \widetilde { \mathcal { W } } _ { i } ^ { ( t ) } \right| } \mathrm { ~ i f ~ } k \in \widetilde { \mathcal { W } } _ { i } ^ { ( t ) } , \qquad \mathrm { ~ a n d ~ } \qquad Q _ { i k } = 0 \mathrm { ~ o t h e r w i s e . }\tag{25}
$$

By the definition of $\widetilde { \mathcal { W } } _ { i } ^ { ( t ) }$ , for every data point $x _ { i }$ and every $k \in \widetilde { \mathcal { W } } _ { i } ^ { ( t ) }$ , it holds that

$$
\langle \tilde { z } _ { k } ^ { ( t ) } , x _ { i } \rangle \geq \langle \tilde { z } _ { y _ { i } } ^ { ( t ) } , x _ { i } \rangle .
$$

\sqrt { 2 } ( K - 1 ) \exp \left( - \eta \frac { \delta } { 2 } \right) \sum _ { j = 0 } ^ { T - 1 } \left( 1 + \frac { \eta } { 2 } \right) ^ { j } < \frac { 2 \sqrt { 2 } ( K - 1 ) } { \eta } .
$$

Since $\begin{array} { r } { \eta \geq \frac { 8 ( K - 1 ) } { \delta } } \end{array}$ , this quantity is indeed less than $\frac { \delta } { 2 { \sqrt { 2 } } }$ , as claimed. This concludes the proof. □

## 5.3 Transferring the guarantees back to the finite-η dynamics

The shadowing lemma immediately gives an exponential bound on the loss at time $T .$ This is the key step in deriving the main theorem from the finite-time termination of the hard perceptron dynamics.

Proposition 5.8. Under the setting of Lemma 5.6, if GD is initialized at $W ^ { ( 0 ) } = 0$ , then

$$
f ( W ^ { ( T ) } ) < ( K - 1 ) e ^ { - \frac { \eta \delta } { 2 } } .
$$

Proof. For all $i \in [ n ]$ , Lemma 5.6 gives

$$
\langle z _ { y _ { i } } ^ { ( T ) } , x _ { i } \rangle \geq \langle z _ { k } ^ { ( T ) } , x _ { i } \rangle + \frac \delta 2 \mathrm { ~ f o r ~ a l l ~ } k \neq y _ { i } .
$$

Going back to the original variable $w _ { k } ^ { ( T ) } = \eta z _ { k } ^ { ( T ) }$ , we obtain

$$
\langle w _ { y _ { i } } ^ { ( T ) } - w _ { k } ^ { ( T ) } , x _ { i } \rangle \geq \frac { \eta \delta } { 2 } ~ \mathrm { f o r ~ a l l } ~ k \neq y _ { i } .
$$

This implies that exp $\begin{array} { r } { \langle \mathcal { w } _ { k } ^ { ( T ) } - \mathcal { w } _ { y _ { i } } ^ { ( T ) } , x _ { i } \rangle ) \le \exp \left( - \frac { \eta \delta } 2 \right) } \end{array}$ for all $k \neq y _ { i }$ , and so by Eq. (1), the softmax probabilities associated to the correct class satisfy

$$
[ P ( W ^ { ( T ) } ) ] _ { i y _ { i } } = \frac { \exp ( \langle w _ { y _ { i } } ^ { ( T ) } , x _ { i } \rangle ) } { \sum _ { j = 1 } ^ { K } \exp ( \langle w _ { j } ^ { ( T ) } , x _ { i } \rangle ) } = \frac { 1 } { 1 + \sum _ { j \in [ K ] , j \neq y _ { i } } \exp ( \langle w _ { j } ^ { ( T ) } - w _ { y _ { i } } ^ { ( T ) } , x _ { i } \rangle ) } \geq \frac { 1 } { 1 + ( K - 1 ) e ^ { - \frac { \pi \delta } { 2 } } } .
$$

Since $- \log ( \cdot )$ is decreasing, and using $\log ( 1 + x ) < x$ for all $x > 0$ , this implies that

$$
f ( W ^ { ( T ) } ) = - \frac { 1 } { n } \sum _ { i = 1 } ^ { n } \log \left( P ( W ^ { ( T ) } ) _ { i y _ { i } } \right) \leq \log \left( 1 + ( K - 1 ) e ^ { - \frac { \eta \delta } { 2 } } \right) < ( K - 1 ) e ^ { - \frac { \eta \delta } { 2 } } ,
$$

which is the claimed bound.

We now use Proposition 5.8 to prove Theorem 5.1. Accordingly, choosing η so that this bound is less than $1 / ( 2 \eta )$ gives $\tau \leq T$ , while choosing it so that the bound is less than ε gives $f ( W ^ { ( T ) } ) \leq \varepsilon$

Proof of Theorem 5.1, part (i). The first two conditions on the step size ensure that we can apply Proposition 5.8, and we obtain $\begin{array} { r } { f ( W ^ { ( T ) } ) < ( K - 1 ) \exp { \left( - \frac { \eta \delta } { 2 } \right) } } \end{array}$ . Then, to show that $\tau \leq T$ , it sufices to show that under the third assumption on the step size it holds that $\begin{array} { r } { ( K - 1 ) \exp \left( - \frac { \eta \delta } { 2 } \right) < \frac { 1 } { 2 \eta } } \end{array}$ , which is equivalent to showing log $\begin{array} { r } { ( 2 \eta ( K - 1 ) ) < \frac { \eta \delta } { 2 } } \end{array}$

Let $\begin{array} { r } { x = \frac { \eta \delta } { 2 } } \end{array}$ and observe that the condition $\begin{array} { r } { \eta \geq \frac { 4 } { \delta } \log \frac { 4 ( K - 1 ) } { \delta } } \end{array}$ implies that $x \geq 2 \log { \frac { 4 ( K - 1 ) } { \delta } }$ . Using this together with $\begin{array} { r } { \log ( \beta ) < \frac { \beta } { 2 } } \end{array}$ for any $\beta > 0$ we obtain

$$
\log ( 2 \eta ( K - 1 ) ) = \log \left( x \frac { 4 ( K - 1 ) } { \delta } \right) = \log ( x ) + \log \left( \frac { 4 ( K - 1 ) } { \delta } \right) < \frac { x } { 2 } + \frac { x } { 2 } = x ,
$$

which, as argued before, shows that $\begin{array} { r } { f ( W ^ { ( T ) } ) < \frac { 1 } { 2 \eta } . } \end{array}$

Proof of Theorem 5.1, part (ii). Again, the first two conditions on the step size ensure that $f ( W ^ { ( T ) } ) <$ $\begin{array} { r } { ( K - 1 ) \exp \left( - \frac { \eta \delta } { 2 } \right) } \end{array}$ . Then, observe that the condition $\begin{array} { r } { \eta \geq \frac { 2 } { \delta } \log \frac { K - 1 } { \varepsilon } } \end{array}$ implies immediately that $( K -$ $1 ) \exp \left( - \frac { \eta \delta } { 2 } \right) \leq \varepsilon .$ , which shows indeed that $f ( W ^ { ( T ) } ) < \varepsilon$ □

## A Equivalence to logistic regression when K = 2

Consider a binary classification dataset $\{ ( x _ { i } , \widetilde { y } _ { i } ) \} _ { i = 1 } ^ { n }$ , where $x _ { i } \in \mathbb { R } ^ { d }$ and $\widetilde { y } _ { i } \in \{ - 1 , 1 \}$ . For $v \in \mathbb { R } ^ { d }$ define the binary logistic loss

$$
f _ { \mathrm { b i n } } ( v ) : = \frac { 1 } { n } \sum _ { i = 1 } ^ { n } \log \left( 1 + \exp \left( - \widetilde { y } _ { i } \langle v , x _ { i } \rangle \right) \right) .\tag{35}
$$

The corresponding maximum margin is $\begin{array} { r } { \gamma _ { \mathrm { b i n } } : = \operatorname* { m a x } _ { \| v \| \leq 1 } \operatorname* { m i n } _ { i \in [ n ] } \widetilde { y } _ { i } \langle v , x _ { i } \rangle } \end{array}$

For the multiclass problem (1) with $K = 2 .$ , we associate to each label $y _ { i } \in \{ 1 , 2 \}$ the binary label $\widetilde { y } _ { i } = 1 \mathrm { ~ i f ~ } y _ { i } = 1 \mathrm { ~ a n d ~ } \widetilde { y } _ { i } = - 1 \mathrm { ~ i f ~ } y _ { i } = 2$ . We denote by $\gamma$ the multiclass maximum margin from Eq. (3).

Proposition A.1. Let $w _ { 1 } , w _ { 2 }$ be the rows of $W \in \mathbb { R } ^ { 2 \times d }$ . GD on the multiclass cross-entropy loss (1) with $K = 2$ is equivalent to GD on the binary logistic regression loss (35) under the identifications

$$
v = w _ { 1 } - w _ { 2 } \qquad f ( W ) = f _ { \mathrm { b i n } } ( v ) , \qquad \eta _ { \mathrm { b i n } } = 2 \eta , \qquad \gamma _ { \mathrm { b i n } } = \frac { \gamma } { \sqrt { 2 } } .
$$

Moreover, if multiclass GD is initialized at $W ^ { ( 0 ) } = 0$ and we define $v _ { t } = w _ { 1 } ^ { ( t ) } - w _ { 2 } ^ { ( t ) }$ , then

$$
w _ { 1 } ^ { ( t ) } = \frac { v _ { t } } { 2 } , \qquad w _ { 2 } ^ { ( t ) } = - \frac { v _ { t } } { 2 }
$$

for all $t \geq 0$ , and $( v _ { t } ) _ { t \geq 0 }$ is the binary logistic GD trajectory with step size $\eta _ { \mathrm { b i n } } = 2 \eta$

Proof. We first show the equivalence of the losses. For $K = 2 .$ , we have

$$
P ( W ) _ { i y _ { i } } = \frac { e ^ { \langle w _ { y _ { i } } , x _ { i } \rangle } } { e ^ { \langle w _ { y _ { i } } , x _ { i } \rangle } + e ^ { \langle w _ { 3 - y _ { i } } , x _ { i } \rangle } } = \frac { 1 } { 1 + e ^ { - \langle w _ { y _ { i } } - w _ { 3 - y _ { i } } , x _ { i } \rangle } } = \frac { 1 } { 1 + e ^ { - \tilde { y } _ { i } \langle w _ { 1 } - w _ { 2 } , x _ { i } \rangle } } ,
$$

where we used $w _ { y _ { i } } - w _ { 3 - y _ { i } } = \widetilde { y } _ { i } ( w _ { 1 } - w _ { 2 } )$ . Therefore, using the definition of f in Eq. (1), we obtain

$$
f ( W ) = \frac { 1 } { n } \sum _ { i = 1 } ^ { n } \log \left( 1 + \exp \left( - \widetilde { y } _ { i } \langle w _ { 1 } - w _ { 2 } , x _ { i } \rangle \right) \right) = f _ { \mathrm { b i n } } ( w _ { 1 } - w _ { 2 } ) .
$$

We next compare the two maximum margins. For any $W \in \mathbb { R } ^ { 2 \times d }$

$$
\begin{array} { r } { \| w _ { 1 } - w _ { 2 } \| ^ { 2 } = 2 \left( \| w _ { 1 } \| ^ { 2 } + \| w _ { 2 } \| ^ { 2 } \right) - \| w _ { 1 } + w _ { 2 } \| ^ { 2 } \leq 2 \| W \| _ { \mathrm { F } } ^ { 2 } . } \end{array}
$$

Thus, $\| W \| _ { \mathrm { F } } \leq 1$ implies $\lVert w _ { 1 } - w _ { 2 } \rVert \leq \sqrt { 2 }$ . Conversely, for any $v \in \mathbb { R } ^ { d }$ such that $\| v \| \leq { \sqrt { 2 } }$ , the choice $\begin{array} { r } { w _ { 1 } = \frac { v } { 2 } , w _ { 2 } = - \frac { v } { 2 } } \end{array}$ satisfies $w _ { 1 } - w _ { 2 } = v$ and $\begin{array} { r } { \| W \| _ { \mathrm { F } } ^ { 2 } = \frac { 1 } { 2 } \| v \| ^ { 2 } \leq 1 } \end{array}$ , so

$$
\left\{ w _ { 1 } - w _ { 2 } | \| W \| _ { \mathrm { F } } \leq 1 \right\} = \left\{ v \in \mathbb { R } ^ { d } \Big | \| v \| \leq \sqrt { 2 } \right\} .
$$

For $K = 2 ,$ the margin of example i is $\widetilde { y } _ { i } \langle w _ { 1 } - w _ { 2 } , x _ { i } \rangle$ . It follows from the previous identity and the definition of $\gamma _ { \mathrm { b i n } }$ that

$$
\gamma = \operatorname* { m a x } _ { \| v \| \leq \sqrt { 2 } } \operatorname* { m i n } _ { i \in [ n ] } \widetilde { y } _ { i } \langle v , x _ { i } \rangle = \sqrt { 2 } \operatorname* { m a x } _ { \| v \| \leq 1 } \operatorname* { m i n } _ { i \in [ n ] } \widetilde { y } _ { i } \langle v , x _ { i } \rangle = \sqrt { 2 } \gamma _ { \mathrm { b i n } } .
$$

Therefore, $\gamma _ { \mathrm { b i n } } = \frac { \gamma } { \sqrt { 2 } }$

Finally, since $f ( W ) = f _ { \mathrm { b i n } } ( w _ { 1 } - w _ { 2 } )$ , the chain rule gives

$$
\nabla _ { w _ { 1 } } f ( W ) = \nabla f _ { \mathrm { b i n } } ( w _ { 1 } - w _ { 2 } ) , \qquad \nabla _ { w _ { 2 } } f ( W ) = - \nabla f _ { \mathrm { b i n } } ( w _ { 1 } - w _ { 2 } ) .
$$

Consequently, for $v _ { t } = w _ { 1 } ^ { ( t ) } - w _ { 2 } ^ { ( t ) }$

$$
v _ { t + 1 } = v _ { t } - 2 \eta \nabla f _ { \mathrm { b i n } } ( v _ { t } ) .
$$

Thus, $( v _ { t } ) _ { t \geq 0 }$ is precisely the binary logistic GD trajectory with $\eta _ { \mathrm { b i n } } = 2 \eta$ .

Moreover, the two row gradients sum to zero, so

$$
w _ { 1 } ^ { ( t + 1 ) } + w _ { 2 } ^ { ( t + 1 ) } = w _ { 1 } ^ { ( t ) } + w _ { 2 } ^ { ( t ) } .
$$

Since $W ^ { ( 0 ) } = 0$ , it follows that $w _ { 1 } ^ { ( t ) } + w _ { 2 } ^ { ( t ) } = 0$ for all $t \geq 0$ . Combining this with $v _ { t } = w _ { 1 } ^ { ( t ) } - w _ { 2 } ^ { ( t ) }$ gives

$$
w _ { 1 } ^ { ( t ) } = \frac { v _ { t } } { 2 } , \qquad w _ { 2 } ^ { ( t ) } = - \frac { v _ { t } } { 2 } ,
$$

as claimed.

## E.4.1 Termination of the hard perceptron (C1)

The same family also illustrates why the dependence of the step-size threshold on δ cannot be avoided. Recall the dataset family $X _ { \eta }$ (58) with all labels equal to 1, and let $\delta _ { \eta }$ denote their corresponding (binary) gaps, as defined in Eq. (46). $$

## E.4.2 Sharpness of the δ-dependency for transitioning to the stable regime (C2)

Now fix the dataset $X _ { \eta }$ and run GD with a generic step size $\alpha > 0$ . The first iterate is
