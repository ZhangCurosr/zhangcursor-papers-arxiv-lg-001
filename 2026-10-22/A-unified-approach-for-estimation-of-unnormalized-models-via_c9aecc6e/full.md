# A unified approach for estimation of unnormalized models via Stein operators

Mitsuki Nagai<sup>∗</sup>

Keisuke Yano<sup>†</sup>

## Abstract

In this paper, we develop a unified framework connecting proper scoring rules and Stein’s method for the estimation of unnormalized models. We construct a class of proper scoring rules that encompasses score matching, ratio matching, pseudolikelihood, and noise contrastive estimation. We show that these proper scoring rules naturally induce Stein operators. This connection yields a new construction principle for Stein operators, and enables us to study estimators based on these scoring rules through the geometry associated with the induced Stein operators. Using this geometric perspective, we provide a unified characterization of the asymptotic eficiency of the resulting estimators.

## 1 Introduction

Consider estimation in a parametric model

$$
\mathcal { P } : = \left\{ p _ { \theta } ( x ) = \frac { \tilde { p } _ { \theta } ( x ) } { Z ( \theta ) } \bigg | \theta \in \Theta \right\}
$$

on a sample space $x ,$ where $\Theta \subset \mathbb { R } ^ { d }$ and $\begin{array} { r } { Z ( \theta ) : = \int _ { \mathcal { X } } \tilde { p } _ { \theta } ( x ) } \end{array}$ dx is a normalizing constant. A normalizing constant is often intractable, making maximum likelihood estimation dificult in many cases; examples include Markov random fields (Besag, 1974), statistical models on manifolds (Mardia and Jupp, 1999; Chikuse, 2003), Boltzmann machines (Ackley et al., 1985), energy-based models (LeCun et al., 2006; Song and Kingma, 2021), and score-based generative models (Lai et al., 2025).

A series of works by Parry et al. (2012), Dawid et al. (2012), and Ehm and Gneiting (2012) developed the theory of proper local scoring rules, providing a framework for estimation in unnormalized models that encompasses pseudolikelihood (Besag, 1975), score matching (Hyv¨arinen, 2005), and ratio matching (Hyv¨arinen, 2007).

More recently, Stein’s method has emerged as an alternative approach to estimation in unnormalized models (Barp et al., 2019; Ebner et al., 2025). This approach employs a Stein operator $\scriptstyle A _ { \theta }$ and a Stein class $\mathcal { F } _ { \theta }$ satisfying the characterization

$$
\begin{array} { r } { \mathrm { E } _ { \theta ^ { \star } } [ \boldsymbol { \mathcal { A } } _ { \theta } f ( \boldsymbol { X } ) ] = 0 , \quad \forall f \in \mathcal { F } _ { \theta } \iff \theta = \theta ^ { \star } . } \end{array}
$$

The pair $( A _ { \theta } , { \mathcal { F } } _ { \theta } )$ is called a Stein pair. Various constructions of Stein pairs have been proposed (e.g., Gorham and Mackey, 2015; Mijoule et al., 2023).

In this paper, we establish a unified approach for a class of proper scoring rules via Stein operators. Given a suitable linear operator L together with a concave function h, we construct a proper scoring rule that does not depend on the normalizing constant. Our class of proper scoring rules encompasses score matching, ratio matching, Besag’s pseudolikelihood, and noise contrastive estimation (Gutmann and Hyv¨arinen, 2010). Moreover, it yields a new construction principle for Stein operators and shows that estimators based on these proper scoring rules can be analyzed through the geometry induced by the corresponding Stein operators. Leveraging this geometric perspective, we provide a unified characterization of the asymptotic eficiency of the resulting estimators.

## 1.1 Related work

Scoring rules Proper scoring rules provide a framework for evaluating the quality of probability distributions (Gneiting and Raftery, 2007). The seminal work of Hyv¨arinen (2005) proposed score matching (Hyv¨arinen scoring rule) for the estimation of unnormalized models on R<sup>p</sup>. Various extensions of score matching to more general domains have been developed (e.g., Dawid and Lauritzen, 2005; Hyv¨arinen, 2007; Lyu, 2009; Yu et al., 2019; Mardia et al., 2016; Liu et al., 2022; Williams and Liu, 2022; Scealy and Wood, 2023). To analyze the asymptotic eficiency of score matching estimators, Koehler et al. (2023) and Qin and Risteski (2024) exploited generators of difusion processes associated with score matching. Closely related to this paper is Lyu (2009), in which score matching was generalized by replacing the gradient operator with a general linear operator L. Another closely related work is Gutmann and Hirayama (2011), in which a unified framework for estimation of unnormalized models was developed based on Bregman divergences. Our framework, which incorporates both a general linear operator L and a Bregman-type divergence generated by a concave function h, reveals the connection between the resulting scoring rules and Stein’s method.

Parry et al. (2012) generalized score matching to local scoring rules and characterized their propriety. Ehm and Gneiting (2012) characterized the propriety of local scoring rules of order two. Takasu et al. (2018) proposed proper local scoring rules on unit spheres. Dawid et al. (2012) introduced local scoring rules on discrete spaces that include pseudolikelihood (Besag, 1975) and ratio matching (Hyv¨arinen, 2007) as special cases. Kanamori and Takenouchi (2017) investigated strictly proper local scoring rules on discrete sample spaces through their relationship with Bregman divergences. Our class of proper scoring rules recovers local scoring rules on both continuous and discrete sample spaces through appropriate choices of L. Marlin and de Freitas (2011) studied the asymptotic relative eficiency of Besag’s pseudolikelihood and ratio matching. Dawid et al. (2016) discussed parametric estimation based on scoring rules. Waghmare and Ziegel (2026) provide a comprehensive review of recent developments in scoring rules.

An alternative approach is noise contrastive estimation (NCE), proposed by Gutmann and Hyv¨arinen (2010), which estimates the normalizing constant rather than employing a scoring rule that does not depend on it. Matsuda and Hyv¨arinen (2019) extended NCE to finite mixtures of unnormalized models. Fujii et al. (2026) generalized NCE using Bregman divergences. Sonobe et al. (2026) developed a fully Bayesian extension of the contrastive approach, thereby enabling posterior uncertainty quantification. Uehara et al. (2020) developed a framework for asymptotically eficient estimation without the normalizing constant by utilizing a nonparametric density estimator.

Stein’s method Stein’s method introduced by Stein (1972) was originally developed for normal approximation, but it now plays an important role in the estimation of unnormalized models (Anastasiou et al., 2023; Liu et al., 2026). Barp et al. (2019) introduced minimum Stein discrepancy estimation and showed that score matching is recovered as a special case using the Langevin–Stein operator. Grathwohl et al. (2020) used neural networks to parameterize the test functions in Stein discrepancies. Ebner et al. (2025) proposed Stein’s method of moments (SMoM), which yields a wide class of estimators that do not depend on the normalizing constant. By choosing appropriate Stein operators, SMoM can be extended to more general domains (Fischer, 2025; Fischer et al., 2025a,b, 2026). Kume and Walker (2026) showed that weighted score matching is an instance of SMoM. Nagai and Yano (2026) characterized the asymptotic eficiency of the score matching estimator using the geometry of SMoM. Extending this geometric approach to our class of proper scoring rules, we show that the resulting estimators are asymptotically eficient if and only if the corresponding Stein score functions and the Fisher score functions span the same space.

For the construction of Stein operators, Gorham and Mackey (2015) and Gorham et al. (2019) proposed a generator approach that exploits the generators of Markov processes. Ley and Swan (2013) and Mijoule et al. (2023) introduced a density approach. Ley and Swan (2016a,b) proposed a parametric approach. Yang et al. (2018) characterized Stein operators on discrete spaces. Eguchi (2026) derived the γ-Stein operator from the γ-divergence. Our construction of Stein operators is based on the estimating equations, or equivalently on the first-order optimality conditions, associated with proper scoring rules.

## 2.1 Notation

Let $( \mathcal { X } , \mathcal { B } , \mathrm { d } x )$ be a measure space. Let the parameter space $\Theta \subset \mathbb { R } ^ { d }$ be an open set, and let $p _ { \theta }$ be a probability density on X such that $p _ { \theta } ( x ) > 0$ and $\theta \mapsto p _ { \theta } ( x )$ is suficiently smooth. The parametric model $\mathcal { P }$ is defined by ${ \mathcal { P } } : = \{ p _ { \theta } ~ | ~ \theta \in \Theta \}$ . We assume that $\mathcal { P }$ is identifiable, that is, $p _ { \theta } = p _ { \theta ^ { \prime } }$ if and only if $\theta = \theta ^ { \prime }$ . For an estimator $\hat { \theta }$ satisfying $\sqrt { n } ( \hat { \theta } - \theta ^ { \star } )  N ( 0 , V )$ , we set $\operatorname { A V a r } [ \hat { \theta } ] : = V$

The standard inner product and the induced norm on $\mathbb { R } ^ { m }$ are denoted by $\langle \cdot , \cdot \rangle$ and $\| \cdot \|$ respectively. The gradient operator on $\Theta$ is denoted by $\nabla _ { \theta }$ . Let $\partial _ { \theta _ { j } }$ denote the partial diferential operator $\partial / \partial \theta _ { j }$

Let $\mathbb { M } ( \mathcal { X } ; \mathbb { R } ^ { m } )$ be the space of all measurable functions from $\mathcal { X }$ to $\mathbb { R } ^ { m }$ . For $r \in \mathbb N$ , define

$$
L ^ { r } ( p _ { \theta } ) : = \{ f \in \mathbb { M } ( \mathcal { X } ; \mathbb { R } ) \mid \operatorname { E } _ { \theta } [ | f ( X ) | ^ { r } ] < \infty \} , \quad L ^ { r } ( \mathcal { P } ) : = \bigcap _ { \theta \in \Theta } L ^ { r } ( p _ { \theta } ) ,
$$

where functions equal almost everywhere are identified in the usual manner.

## 2.2 Scoring rules

A scoring rule is a loss function $S \colon \mathcal { X } \times \mathcal { P }  \mathbb { R }$ such that $( x \mapsto S ( x , p _ { \theta } ) ) \in L ^ { 1 } ( \mathcal { P } )$ for all $\theta \in \Theta$ The scoring rule S is said to be proper if for any (true) parameter $\theta ^ { \star } \in \Theta , \theta \mapsto \mathrm { E } _ { \theta ^ { \star } } [ S ( X , p _ { \theta } ) ]$ is minimized at $\theta = \theta ^ { \star }$ . S is said to be strictly proper if the minimizer is unique. Propriety justifies the use of a scoring rule S as a loss function. A proper scoring rule S induces the statistical divergence

$$
D ( p _ { \theta ^ { \star } } \parallel p _ { \theta } ) : = \mathrm { E } _ { \theta ^ { \star } } [ S ( X , p _ { \theta } ) ] - \mathrm { E } _ { \theta ^ { \star } } [ S ( X , p _ { \theta ^ { \star } } ) ] .
$$

$D ( p _ { \theta ^ { \star } } \parallel p _ { \theta } ) \geq 0$ whenever $S$ is proper. If S is strictly proper, $D ( p _ { \theta ^ { \star } } \parallel p _ { \theta } ) = 0$ if and only if $\theta = \theta ^ { \star }$ Let $X _ { 1 } , \ldots , X _ { n }$ be i.i.d. random variables from $p _ { \theta ^ { \star } }$ . The estimator <sup>ˆ</sup>θ based on a proper scoring rule S is defined by

$$
{ \hat { \theta } } \in \operatorname { a r g m i n } _ { \theta \in \Theta } { \frac { 1 } { n } } \sum _ { i = 1 } ^ { n } S ( X _ { i } , p _ { \theta } ) .\tag{1}
$$

The maximum likelihood estimator $ { \hat { \theta } } _ { \mathrm { M L E } }$ corresponds to the log score $S ( x , p _ { \theta } ) : = - \log p _ { \theta } ( x )$

## 2.3 Stein’s method

For $\theta \in \Theta$ , let $\scriptstyle A _ { \theta }$ be a linear operator on $L ^ { 2 } ( p _ { \theta } )$ with the domain Dom $\mathcal { A } _ { \theta }$ . Let $\mathcal { F } _ { \theta } \subset \{ f \in \operatorname { D o m } \mathcal { A } _ { \theta } \mid$ $\mathcal { A } _ { \theta } f \in L ^ { 1 } ( \mathcal { P } ) \}$ be a class of test functions. The pair $( { \mathcal { A } } _ { \theta } , { \mathcal { F } } _ { \theta } )$ is said to be a Stein pair if for any $\theta ^ { \star } \in \Theta$

$$
\begin{array} { r } { \mathrm { E } _ { \theta ^ { \star } } [ \boldsymbol { \mathcal { A } } _ { \theta } f ( \boldsymbol { X } ) ] = 0 , \quad \forall f \in \mathcal { F } _ { \theta } \iff \theta = \theta ^ { \star } . } \end{array}
$$

For a Stein pair $( { \mathcal { A } } _ { \theta } , { \mathcal { F } } _ { \theta } ) , { \mathcal { A } } _ { \theta }$ is called a Stein operator and $\mathcal { F } _ { \theta }$ is called a Stein class. We provide some examples of Stein operators in Section 5.

## 3.1 Proper scoring rules for unnormalized models

We construct scoring rules as follows. Let $\mathcal { V } \subset \mathbb { R } ^ { m }$ be an open convex set and $h \colon \mathcal { X } \times \mathcal { Y }  \mathbb { R }$ be a measurable function such that $y \mapsto h ( x , y )$ is suficiently smooth. The gradient and Hessian of h with respect to $y$ are denoted by $h _ { y } ( x , y )$ and $h _ { y y } ( x , y )$ , respectively. Here, the second argument of $h _ { y }$ and $h _ { y y }$ specifies the evaluation point of the derivatives with respect to y. Let L: Dom $\mathcal { L } \subset$ $\mathbb { M } ( \mathcal { X } ; \mathbb { R } )  \mathbb { M } ( \mathcal { X } ; \mathbb { R } ^ { m } )$ be a linear operator satisfying $p _ { \theta } ~ \in$ Dom L and $\mathcal { L } p _ { \theta } ( x ) / p _ { \theta } ( x ) \in \mathcal { V }$ for all $x \in \mathcal { X }$ and $\theta \in \Theta$ . Let $\mathcal { L } ^ { \ast }$ : Dom $\mathcal { L } ^ { * } \subset \mathbb { M } ( \mathcal { X } ; \mathbb { R } ^ { m } )  \mathbb { M } ( \mathcal { X } ; \mathbb { R } )$ be a linear operator that is adjoint to $\mathcal { L }$ in the following sense: for every $f \in \operatorname { D o m } { \mathcal { L } }$ and $V \in \operatorname { D o m } \mathcal { L } ^ { * }$ 2

$$
\int _ { \mathcal { X } } f ( x ) \mathcal { L } ^ { * } V ( x ) \mathrm { d } x = \int _ { \mathcal { X } } \langle V ( x ) , \mathcal { L } f ( x ) \rangle \mathrm { d } x ,\tag{2}
$$

whenever $f { \mathcal { L } } ^ { * } V$ and $\langle V ( \cdot ) , \mathcal { L } f ( \cdot ) \rangle$ are integrable.

We assume the following identifiability condition on $\mathcal { L }$

Assumption 1. For all $\theta , \theta ^ { \star } \in \Theta$ , the equation $\mathcal { L } p _ { \theta } / p _ { \theta } = \mathcal { L } p _ { \theta ^ { \star } } / p _ { \theta }$ ⋆ holds if and only if $\theta = \theta ^ { \star }$

We impose regularity conditions on $\mathcal { L }$ and h detailed in Appendix A, ensuring that all relevant expectations are finite and the functions involved lie in the appropriate operator domains. Under the regularity conditions, the scoring rule $S \colon \mathcal { X } \times \mathcal { P } $ R is defined by

$$
S ( x , p _ { \theta } ) : = h \left( x , \frac { \mathcal { L } p _ { \theta } ( x ) } { p _ { \theta } ( x ) } \right) + \mathcal { L } ^ { * } h _ { y } \left( \cdot , \frac { \mathcal { L } p _ { \theta } ( \cdot ) } { p _ { \theta } ( \cdot ) } \right) ( x ) - \biggl \langle h _ { y } \left( x , \frac { \mathcal { L } p _ { \theta } ( x ) } { p _ { \theta } ( x ) } \right) , \frac { \mathcal { L } p _ { \theta } ( x ) } { p _ { \theta } ( x ) } \biggr \rangle .\tag{3}
$$

In general, S does not require computation of the normalizing constant, since $\mathcal { L } p _ { \theta } / p _ { \theta }$ is independent of it. The exception is when L itself generates an additional term involving the normalizing constants; see Sections 5.4 and 5.5.

If $y \mapsto h ( x , y )$ is concave, the scoring rule S induces the following Bregman-type divergence:

$$
\begin{array} { r l } & { D ( p _ { \theta ^ { \star } } \parallel p _ { \theta } ) : = \mathrm { E } _ { \theta ^ { \star } } [ S ( X , p _ { \theta } ) - S ( X , p _ { \theta ^ { \star } } ) ] } \\ & { \qquad = \mathrm { E } _ { \theta ^ { \star } } \left[ h \left( X , \frac { \mathcal { L } p _ { \theta } ( X ) } { p _ { \theta } ( X ) } \right) - h \left( X , \frac { \mathcal { L } p _ { \theta ^ { \star } } ( X ) } { p _ { \theta ^ { \star } } ( X ) } \right) \right. } \\ & { \qquad \left. - \left. h _ { y } \left( X , \frac { \mathcal { L } p _ { \theta } ( X ) } { p _ { \theta } ( X ) } \right) , \frac { \mathcal { L } p _ { \theta } ( X ) } { p _ { \theta } ( X ) } - \frac { \mathcal { L } p _ { \theta ^ { \star } } ( X ) } { p _ { \theta ^ { \star } } ( X ) } \right. \right] . } \end{array}\tag{4}
$$

The following theorem shows that a linear operator L and a concave function h yield a proper scoring rule.

Theorem 1. Suppose $y \mapsto h ( x , y )$ is concave. Then, the scoring rule S defined by (3) is proper.   
Furthermore, $i f y \mapsto h ( x , y )$ is strictly concave, and if L satisfies Assumption 1, S is strictly proper.

Proof. By the concavity of h, $D ( p _ { \theta ^ { \star } } \parallel p _ { \theta } )$ defined by (4) is nonnegative for any $\theta , \theta ^ { \star } \in \Theta$ . Thus, S is a proper scoring rule. Furthermore, if h is strictly concave, $D ( p _ { \theta ^ { \star } } \parallel p _ { \theta } ) = 0$ if and only if $\mathcal { L } p _ { \theta } / p _ { \theta } = \mathcal { L } p _ { \theta ^ { \star } } / p _ { \theta ^ { \star } }$ . Under Assumption 1, this is equivalent to $\theta = \theta ^ { \star }$ . Therefore, S is strictly proper, which completes the proof. □

Remark 1 (Comparison with Lyu (2009)). Generalized score matching (Lyu, 2009) is the proper scoring rule given by

$$
S ( x , p _ { \theta } ) : = \frac { 1 } { 2 } \bigg \| \frac { \mathcal { L } p _ { \theta } ( x ) } { p _ { \theta } ( x ) } \bigg \| ^ { 2 } - \mathcal { L } ^ { * } \left[ \frac { \mathcal { L } p _ { \theta } } { p _ { \theta } } \right] ( x ) .
$$

This scoring rule is recovered by choosing $h ( x , y ) : = - \| y \| ^ { 2 } / 2$ . Allowing a general concave function h is essential for the scope of our framework: together with appropriate choices of L, it encompasses important examples; see Section 5. Moreover, the curvature $h _ { y y }$ determines the geometry of the associated divergence and, consequently, the induced Stein operator.

Remark 2 (Comparison with Takasu et al. (2018)). Takasu et al. (2018) proposed proper local scoring rules on the unit sphere $\mathbb { S } ^ { p - 1 }$ . Their construction is recovered by choosing the Riemannian gradient ${ \mathcal { L } } : = \nabla _ { \mathbb { S } ^ { p - 1 } }$

Remark 3 (Comparison with Gutmann and Hirayama (2011)). For estimation of unnormalized models, Gutmann and Hirayama (2011) provided a unified framework based on Bregman divergences. Although their framework encompasses the divergence defined in (4), our focus is diferent. We study Bregman divergences that are empirically estimable through proper scoring rules. This representation naturally induces an associated Stein operator and enables a unified analysis of the asymptotic eficiency of the resulting estimators.

## 3.2 Stein operators induced by proper scoring rules

For each $\theta \in \Theta$ , the linear operator $\mathcal { A } _ { \theta }$ on $L ^ { 2 } ( p _ { \theta } )$ is defined as follows.

$$
\mathcal { A } _ { \theta } f ( x ) : = \mathcal { L } ^ { * } \left[ h _ { y y } \left( \cdot , \frac { \mathcal { L } p _ { \theta } ( \cdot ) } { p _ { \theta } ( \cdot ) } \right) \mathcal { D } _ { \theta } f \right] ( x ) - \bigg \langle h _ { y y } \left( x , \frac { \mathcal { L } p _ { \theta } ( x ) } { p _ { \theta } ( x ) } \right) \mathcal { D } _ { \theta } f ( x ) , \frac { \mathcal { L } p _ { \theta } ( x ) } { p _ { \theta } ( x ) } \bigg \rangle ,\tag{5}
$$

where $\mathcal { D } _ { \theta } f$ is defined by

$$
\mathcal { D } _ { \theta } f ( x ) : = \frac { \mathcal { L } [ f p _ { \theta } ] ( x ) - f ( x ) \mathcal { L } p _ { \theta } ( x ) } { p _ { \theta } ( x ) } .
$$

The domain Dom $\mathcal { A } _ { \theta } \subset L ^ { 2 } ( p _ { \theta } )$ and its subset $\mathcal { F } _ { \theta } \subset \operatorname { D o m } \mathcal { A } _ { \theta }$ are chosen to satisfy appropriate integrability conditions and domain requirements for $\mathcal { L }$ and $\mathcal { L } ^ { \ast }$ . The details are given in Appendix A.

To derive $\scriptstyle A _ { \theta }$ from the proper scoring rule S defined by (3), we make the following commutation assumption.

Assumption 2. For $j = 1 , \ldots , d ,$

$$
\begin{array} { c } { \displaystyle \partial _ { \theta _ { j } } \mathcal { L } p _ { \theta } = \mathcal { L } \partial _ { \theta _ { j } } p _ { \theta } , } \\ { \displaystyle \partial _ { \theta _ { j } } \mathcal { L } ^ { * } \left[ h _ { y } \left( \cdot , \frac { \mathcal { L } p _ { \theta } ( \cdot ) } { p _ { \theta } ( \cdot ) } \right) \right] = \mathcal { L } ^ { * } \left[ \partial _ { \theta _ { j } } h _ { y } \left( \cdot , \frac { \mathcal { L } p _ { \theta } ( \cdot ) } { p _ { \theta } ( \cdot ) } \right) \right] . } \end{array}
$$

The following theorem states that the linear operator $\scriptstyle A _ { \theta }$ is naturally induced by the proper scoring rule S and that Stein’s identity holds.

Theorem 2. Let S be the scoring rule defined by (3) and $\scriptstyle A _ { \theta }$ be the linear operator defined by (5).

1. Suppose $\partial _ { \theta _ { j } }$ log $p _ { \theta } \in$ Dom A<sub>θ</sub> for $j = 1 , \ldots , d .$ . Then, under Assumption ${ \mathcal { Q } } ,$ we have

$$
\partial _ { \theta _ { j } } S ( x , p _ { \theta } ) = \mathcal { A } _ { \theta } \partial _ { \theta _ { j } } \log p _ { \theta } ( x ) , \quad j = 1 , \ldots , d .
$$

2. For any $f \in \operatorname { D o m } A _ { \theta }$ , we have $\operatorname { E } _ { \theta } [ \mathcal { A } _ { \theta } f ( X ) ] = 0$

Proof. (1): Observe that

$$
\partial _ { \theta _ { j } } \frac { \mathcal { L } p _ { \theta } ( x ) } { p _ { \theta } ( x ) } = \mathcal { D } _ { \theta } \partial _ { \theta _ { j } } \log p _ { \theta } ( x ) , \quad j = 1 , \ldots , d .
$$

Thus, for $j = 1 , \ldots , d ,$ we have

$$
\begin{array} { r l } & { \partial _ { \theta _ { j } } S ( x , p _ { \theta } ) = \left. h _ { y } \left( x , \frac { \mathcal { L } p \theta \left( x \right) } { p _ { \theta } \left( x \right) } \right) , { \mathcal { D } _ { \theta } \partial _ { \theta _ { j } } \log p _ { \theta } ( x ) } \right. + \mathcal { L } ^ { * } \left[ h _ { y y } \left( \cdot , \frac { \mathcal { L } p \theta \left( \cdot \right) } { p _ { \theta } \left( \cdot \right) } \right) { \mathcal { D } _ { \theta } \partial _ { \theta _ { j } } \log p _ { \theta } } \right] ( x ) } \\ & { \qquad - \left. h _ { y y } \left( x , \frac { \mathcal { L } p _ { \theta } \left( x \right) } { p _ { \theta } \left( x \right) } \right) { \mathcal { D } _ { \theta } \partial _ { \theta _ { j } } \log p _ { \theta } ( x ) } , \frac { \mathcal { L } p _ { \theta } \left( x \right) } { p _ { \theta } \left( x \right) } \right. - \left. h _ { y } \left( x , \frac { \mathcal { L } p _ { \theta } \left( x \right) } { p _ { \theta } \left( x \right) } \right) , { \mathcal { D } _ { \theta } \partial _ { \theta _ { j } } \log p _ { \theta } ( x ) } \right. } \\ & { = \mathcal { A } _ { \theta } \partial _ { \theta _ { i } } \log p _ { \theta } ( x ) , } \end{array}

which proves (1). (2): This follows directly from the adjoint relation (2).

Remark 4 (Connection to SMoM). Let $X _ { 1 } , \ldots , X _ { n }$ be i.i.d. random variables from $p _ { \theta ^ { \star } }$ . A Stein’s method of moments (SMoM) estimator with respect to the test functions $f _ { \theta , 1 } , \dotsc , f _ { \theta , d } \in$ Dom $\scriptstyle A _ { \theta }$ is defined as a solution to the following estimating equations (Ebner et al., 2025):

$$
\sum _ { i = 1 } ^ { n } { \cal A } _ { \theta } f _ { \theta , j } ( X _ { i } ) = 0 , \quad j = 1 , \ldots , d .
$$

Part (1) of Theorem 2 shows that the first-order estimating equations associated with the estimator defined by (1), with S given by (3), coincide with those of an SMoM estimator with test functions $f _ { \theta , j } : = \partial _ { \theta _ { \hat { \imath } } }$ log $p _ { \theta } , j = 1 , \ldots , d .$ This relation provides a canonical choice of test functions (Nagai and Yano, 2026).

Remark 5 (Comparison with Eguchi (2026)). Eguchi (2026) derived the γ-Stein operator by taking the first variation of the γ-divergence along infinitesimal transports induced by a geometry on the sample space. In contrast, our construction is based on the divergence geometry induced by a scoring rule. Consequently, when applied to the γ-divergence (pseudo-spherical scoring rule), our construction yields a Stein operator distinct from the γ-Stein operator of Eguchi (2026); see Appendix C.2.

The following proposition gives a suficient condition for $( A _ { \theta } , { \mathcal { F } } _ { \theta } )$ to be a Stein pair under a strong integrability condition. In Section 5, we relax this condition for specific choices of L.

Proposition 1. Suppose that $p _ { \theta ^ { \star } } / p _ { \theta } \in \mathcal { F } _ { \theta }$ for all $\theta ^ { \star } , \theta \in \Theta$ and that $h _ { y y } ( x , y )$ is negative definite.   
Then, under Assumption $\quad 1 , \ ( { \mathcal { A } } _ { \theta } , { \mathcal { F } } _ { \theta } )$ is a Stein pair.

Proof. Fix an arbitrary $\theta ^ { \star } \in \Theta$ . We show that for $f _ { \theta } : = p _ { \theta ^ { \star } } / p _ { \theta } \in \mathcal { F } _ { \theta } , \mathrm { E } _ { \theta ^ { \star } } [ A _ { \theta } f _ { \theta } ( X ) ] = 0$ implies $\theta = \theta ^ { \star }$ . $$

## 5.4 Noise-weighted integral operator and noise contrastive estimation

Let $n ( x ) > 0$ be a probability density on $\mathcal { X } ,$ , and $\begin{array} { r } { \mathcal { L } f ( x ) : = n ( x ) \int _ { \mathcal { X } } f ( x ) } \end{array}$ dx. $\mathcal { L } ^ { \ast }$ is given by $\mathcal { L } ^ { \ast } f ( x ) : =$ $\operatorname { E } _ { n } [ f ( W ) ]$ , where $W \sim n ( \cdot )$ . $$

## 6 Conclusion

We have developed a unified framework that connects proper scoring rules and Stein’s method. Our class of proper scoring rules encompasses the principal methods for estimation in unnormalized models, including score matching, ratio matching, pseudolikelihood, and noise contrastive estimation. We have shown that these scoring rules naturally induce Stein operators through their estimating equations, which provides a new principle for constructing Stein operators. Using the geometry induced by these operators, we have established a unified characterization of the asymptotic eficiency of the resulting estimators.
